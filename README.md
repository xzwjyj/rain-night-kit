# 《雨夜取件》AI 短剧创作资源包

一套可以直接照着做出第一支 30 秒竖屏 AI 短剧样片的完整制作档案。来自 [黄果 huangguo.date](https://huangguo.date/) 的原创练习《雨夜取件》。

## 包内文件（7 份）

| 文件 | 用途 |
| --- | --- |
| `剧本-雨夜取件.txt` | 六场次完整剧本：对白、音效标注与授权说明 |
| `角色设定-维修员.csv` | 出镜角色的固定项与参考图组清单 |
| `分镜表-六镜头.csv` | 环境 / 目标 / 障碍 / 发现 / 选择 / 收束 六镜头分镜 |
| `AI提示词-六镜头.csv` | 逐镜提示词与尝试记录表 |
| `配音音效表-雨夜取件.csv` | 2 句独白 + 8 组音效与三遍终检清单 |
| `成本预算示例-雨夜取件.csv` | 预算演算示例（全部数字为假设，非报价） |
| `常见问题-雨夜取件.txt` | 8 条制作常见问题解答 |

## 快速开始

1. 读剧本，确认「观众必须看懂的三件事」。
2. 按 `分镜表-六镜头.csv` 逐镜填写信息任务，先不做世界观扩写。
3. 用 `AI提示词-六镜头.csv` 的结构写提示词：主体 + 环境 + 单一动作 + 景别 + 运动 + 光线。
4. 先做第 02、04 两个相邻镜头的一致性测试，统计可用率，再批量生成。
5. 用 [在线成本计算器](https://huangguo.date/academy/shot-cost-calculator) 把你的实测可用率换算成预算。

## 成本口径

包内预算示例的所有数字（生成单价、40% 可用率、时薪等）均为演示算法的**假设**，不代表任何生成工具的实际价格。建议先用约 10 次小样本实测可用率，再用你自己的账单数字替换。
